# Référence

Le thème n'a aucune API Python à appeler — le paquet ci-dessous n'existe que pour porter les modèles et le point d'entrée `mkdocs.themes`. Il est rendu ici par [mkdocstrings](guide/plugins.md#mkdocstrings), afin que la prise en charge du balisage de ce plugin par le thème soit mise à l'épreuve à chaque build.
