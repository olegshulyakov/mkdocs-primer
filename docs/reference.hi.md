# रेफ़रेंस

थीम में call करने के लिए कोई Python API नहीं है — नीचे दिया package सिर्फ़ templates और `mkdocs.themes` entry point को साथ रखने के लिए है। इसे यहाँ [mkdocstrings](guide/plugins.md#mkdocstrings) से render किया गया है, ताकि हर build पर उस plugin के markup को थीम कैसे संभालती है, यह परखा जाए।
