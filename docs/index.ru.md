# Тема MkDocs Primer

Тема для [MkDocs](https://www.mkdocs.org/), построенная на [дизайн-системе Primer
от GitHub](https://primer.style/): документация, которая выглядит так, будто
она и живёт на GitHub.

Этот сайт — тема, которая отображает саму себя. Статья, которую вы читаете,
оформлена собственными правилами `.markdown-body` от GitHub, а всё вокруг неё —
шапка, дерево навигации, навигационная цепочка, оглавление в правой колонке —
это то, что ваш сайт получает от двух строк конфигурации.

<a id="install"></a>

## Установка

```console
$ pip install mkdocs-primer
```

```yaml
# mkdocs.yml
theme:
  name: primer
```

На этом настройка закончена: у каждой опции есть рабочее значение по умолчанию,
а тема отображает `nav`, который MkDocs уже построил. См. [Установка](guide/installation.md).

<a id="what-you-get"></a>

## Что вы получаете

- **Статья выглядит так, как её отображает GitHub**: типографика, таблицы,
  оформление кода и якоря при наведении, как у README на github.com. CSS Primer
  включён в пакет, поэтому для установки темы не нужен инструментарий Node.
- **Светлый и тёмный режимы** на основе цветовых примитивов Primer. Переключатель
  в шапке следует настройкам операционной системы, пока посетитель не выберет
  режим сам, а затем запоминает выбор. Подсветка синтаксиса тоже следует ему.
- **Навигация, которая масштабируется**: боковая панель с неограниченной
  вложенностью, свёрнутая до раздела, в котором находится читатель, а также
  навигационная цепочка, ссылки «Назад»/«Далее», страница поиска и страница 404.
- **Блоки-примечания в стиле оповещений GitHub.** Расширение `admonition` не
  поставляет CSS, а в `@primer/css` для него нет правил, поэтому в большинстве
  тем `!!! note` отображается без оформления.
- **Семь языков** для собственных текстов темы — английский, испанский,
  французский, хинди, португальский, русский и китайский — и макеты справа налево.
- **Поддержка плагинов, которым нужна помощь темы**: индексные страницы
  разделов, переведённые сайты, даты редакций и авторы, автообнаружение RSS и
  селектор версий mike.
