# गाइड

तीन पेज, उसी क्रम में जिसमें आपको उनकी ज़रूरत पड़ेगी:

- [इंस्टॉलेशन](installation.md) — पैकेज इंस्टॉल करें और `theme.name` को उस पर
  सेट करें।
- [कॉन्फ़िगरेशन](configuration.md) — थीम के विकल्प और वे Markdown एक्सटेंशन
  जिन्हें चालू करना उपयोगी है।
- [प्लगइन](plugins.md) — यह थीम किन MkDocs प्लगइन के साथ परखी गई है, और हर
  प्लगइन को थीम से क्या चाहिए।

यही पेज साइडबार में **गाइड** प्रविष्टि भी है। यह
[mkdocs-section-index](plugins.md#mkdocs-section-index) का काम है: सेक्शन का
लेबल निष्क्रिय टेक्स्ट नहीं, बल्कि एक लिंक होता है।
