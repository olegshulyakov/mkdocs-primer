# Installation

Installez le thème depuis PyPI :

```console
$ pip install mkdocs-primer
```

Puis sélectionnez-le dans `mkdocs.yml` :

```yaml
theme:
  name: primer
```

C'est toute la configuration : chaque option ci-dessous a une valeur par défaut qui fonctionne.

Le thème fonctionne de la même façon avec [ProperDocs](https://properdocs.org/), la continuation de MkDocs 1.x. Installez-le avec `pip install properdocs` et construisez avec `properdocs build`. Il lit le même `mkdocs.yml`.
