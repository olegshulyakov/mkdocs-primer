# Глубоко вложенная страница

Эта страница нужна для того, чтобы у боковой панели было больше одного уровня
вложенности, а у навигационной цепочки — страница с двумя предками.

Элементы, которые она раньше демонстрировала, теперь на странице
[Элементы](../../elements.md): там их проще найти, и там каждый тип
блока-примечания нарисован, а не описан.
