# Una página muy anidada

Esta página existe para que la barra lateral tenga más de un nivel de
anidamiento que renderizar, y para que la ruta de navegación tenga una página
con dos antecesores que dibujar.

Los elementos que mostraba antes están en [Elementos](../../elements.md), donde
son más fáciles de encontrar y donde cada tipo de advertencia se dibuja en
lugar de describirse.
