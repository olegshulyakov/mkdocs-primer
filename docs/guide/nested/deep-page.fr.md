# Une page profondément imbriquée

Cette page existe pour que la barre latérale ait plus d'un niveau d'imbrication à afficher,
et pour que le fil d'Ariane ait une page à deux ancêtres à dessiner.

Les éléments qu'elle présentait autrefois se trouvent sur [Éléments](../../elements.md), où
ils sont plus faciles à trouver et où chaque type d'admonition est présenté plutôt que
décrit.
