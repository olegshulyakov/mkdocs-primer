# Uma página profundamente aninhada

Esta página existe para que a barra lateral tenha mais de um nível de aninhamento a renderizar,
e para que a trilha de navegação tenha uma página com dois ancestrais para desenhar.

Os elementos que ela demonstrava antes estão em [Elementos](../../elements.md), onde
são mais fáceis de encontrar e onde cada tipo de admonition é desenhado, em vez de
descrito.
