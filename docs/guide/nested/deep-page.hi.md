# गहराई में नेस्टेड एक पेज

यह पेज इसलिए है ताकि sidebar के पास render करने के लिए nesting का एक से ज़्यादा
स्तर हो, और breadcrumb trail के पास दो ancestors वाला एक पेज हो।

जो elements यह पहले दिखाता था, वे अब [एलिमेंट्स](../../elements.md) पर हैं, जहाँ
उन्हें ढूँढना आसान है और जहाँ हर admonition type का वर्णन नहीं, बल्कि उसे draw
करके दिखाया गया है।
