# Instalación

Instala el tema desde PyPI:

```console
$ pip install mkdocs-primer
```

Después selecciónalo en `mkdocs.yml`:

```yaml
theme:
  name: primer
```

Esa es toda la configuración: cada opción de abajo tiene un valor por defecto que funciona.

El tema funciona igual con [ProperDocs](https://properdocs.org/), la continuación de MkDocs 1.x. Instálalo con `pip install properdocs` y compila con `properdocs build`. Lee el mismo `mkdocs.yml`.
