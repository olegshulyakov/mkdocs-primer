# Guía

Tres páginas, en el orden en que las necesitarás:

- [Instalación](installation.md) — instalar el paquete y apuntar `theme.name`
  hacia él.
- [Configuración](configuration.md) — las opciones del tema y las extensiones de
  Markdown que conviene activar.
- [Plugins](plugins.md) — con qué plugins de MkDocs está probado este tema y qué
  necesita cada uno del tema.

Esta página es también la entrada **Guía** de la barra lateral. Así funciona [mkdocs-section-index](plugins.md#mkdocs-section-index): la etiqueta de la sección es un enlace y no texto muerto.
