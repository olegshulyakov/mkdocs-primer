# इंस्टॉलेशन

थीम को PyPI से इंस्टॉल करें:

```console
$ pip install mkdocs-primer
```

फिर उसे `mkdocs.yml` में चुनें:

```yaml
theme:
  name: primer
```

बस इतना ही सेटअप है — नीचे दिए हर विकल्प का एक कारगर डिफ़ॉल्ट मान है।

यह थीम [ProperDocs](https://properdocs.org/) के साथ भी वैसे ही काम करती है, जो MkDocs 1.x को आगे जारी रखता है। इसे `pip install properdocs` से इंस्टॉल करें और `properdocs build` से बिल्ड करें। यह वही `mkdocs.yml` पढ़ता है।
