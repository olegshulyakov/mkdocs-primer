# 指南

三个页面，按你会需要的顺序排列：

- [安装](installation.md) —— 安装软件包，并把 `theme.name` 指向它。
- [配置](configuration.md) —— 主题选项，以及值得开启的 Markdown 扩展。
- [插件](plugins.md) —— 本主题针对哪些 MkDocs 插件做过验证，以及每个插件对主题有
  什么要求。

本页同时也是侧边栏中的 **指南** 条目。这正是
[mkdocs-section-index](plugins.md#mkdocs-section-index) 的作用：分区标题是一个
链接，而不是不可点击的文字。
