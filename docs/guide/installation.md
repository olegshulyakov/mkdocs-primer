# Installation

Install the theme from PyPI:

```console
$ pip install mkdocs-primer
```

Then select it in `mkdocs.yml`:

```yaml
theme:
  name: primer
```

That is the whole setup. Every option below has a working default.

The theme works the same with [ProperDocs](https://properdocs.org/), the continuation of MkDocs 1.x. Install it with `pip install properdocs` and build with `properdocs build`. It reads the same `mkdocs.yml`.
