# Руководство

Три страницы в том порядке, в котором они пригодятся:

- [Установка](installation.md) — установить пакет и указать его в `theme.name`.
- [Настройка](configuration.md) — опции темы и расширения Markdown, которые
  стоит включить.
- [Плагины](plugins.md) — с какими плагинами MkDocs тема проверена и что каждый
  из них требует от темы.

Эта же страница — пункт **Руководство** в боковом меню. Так работает
[mkdocs-section-index](plugins.md#mkdocs-section-index): заголовок раздела
является ссылкой, а не просто текстом.
