# Instalação

Instale o tema a partir do PyPI:

```console
$ pip install mkdocs-primer
```

Depois selecione-o no `mkdocs.yml`:

```yaml
theme:
  name: primer
```

É toda a configuração — cada opção abaixo tem um valor padrão que funciona.

O tema funciona do mesmo jeito com o [ProperDocs](https://properdocs.org/), a continuação do MkDocs 1.x. Instale com `pip install properdocs` e gere o site com `properdocs build`. Ele lê o mesmo `mkdocs.yml`.
