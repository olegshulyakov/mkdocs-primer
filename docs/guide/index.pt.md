# Guia

Três páginas, na ordem em que você vai precisar delas:

- [Instalação](installation.md) — instalar o pacote e apontar `theme.name` para
  ele.
- [Configuração](configuration.md) — as opções do tema e as extensões do
  Markdown que valem a pena ativar.
- [Plugins](plugins.md) — com quais plugins do MkDocs este tema foi testado e o
  que cada um exige do tema.

Esta página também é o item **Guia** na barra lateral. É o [mkdocs-section-index](plugins.md#mkdocs-section-index) em ação: o rótulo da seção é um link, e não texto morto.
