# Referencia

El tema no tiene ninguna API de Python a la que llamar: el paquete que aparece a continuación solo existe para contener las plantillas y el punto de entrada `mkdocs.themes`. Aquí lo renderiza [mkdocstrings](guide/plugins.md#mkdocstrings), de modo que en cada compilación se pone a prueba cómo trata el tema el marcado de ese plugin.
