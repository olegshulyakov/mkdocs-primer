# Справочник

У темы нет Python API, который можно вызывать, — пакет ниже существует только для того, чтобы содержать шаблоны и точку входа `mkdocs.themes`. Здесь он отображается с помощью [mkdocstrings](guide/plugins.md#mkdocstrings), чтобы обработка разметки этого плагина темой проверялась при каждой сборке.
